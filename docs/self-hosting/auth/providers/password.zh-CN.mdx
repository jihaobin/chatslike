# 配置邮箱密码账号能力

LobeHub 支持用于注册、密码重置和管理员账号管理的邮箱密码账号能力。当前登录页面展示的是手机验证码和微信登录。本指南介绍仍适用于账号创建和恢复流程的后端邮箱密码配置。

## 默认行为

默认情况下，邮箱密码账号能力已启用。用户可以使用邮箱地址注册并设置密码。

## 配置选项

### 禁用邮箱密码账号能力（仅 SSO 模式）

如果你希望禁用邮箱密码注册和基于密码的账号流程，请设置以下环境变量：

| 环境变量                          | 类型 | 描述                 |
| ----------------------------- | -- | ------------------ |
| `AUTH_DISABLE_EMAIL_PASSWORD` | 可选 | 设置为 `1` 禁用邮箱密码账号流程 |

启用后：

- 当前登录页面仍提供手机验证码和微信登录
- 注册页面重定向到登录页面
- 用户也可以通过配置的 SSO 提供商进行身份验证

<Callout type={'warning'}>
  启用仅 SSO 模式前，请确保已通过 `AUTH_SSO_PROVIDERS` 配置了至少一个 SSO
  提供商，或配置了其他非密码登录方式。否则用户可能无法登录。
</Callout>

### 启用邮箱验证

要求用户在登录前验证邮箱地址：

| 环境变量                      | 类型 | 描述             |
| ------------------------- | -- | -------------- |
| `AUTH_EMAIL_VERIFICATION` | 可选 | 设置为 `1` 启用邮箱验证 |

这需要配置邮件服务（SMTP）。详情请参阅[邮件服务配置](/zh/docs/self-hosting/auth/email)。

## 修改密码

用户可以通过以下两种方式修改密码：

1. **个人设置**：前往 设置 > 个人资料 修改密码
2. **忘记密码**：通过重置密码页面或管理员支持的恢复流程发送密码重置邮件

<Callout type={'info'}>
  以上两种方式都需要配置邮件服务（SMTP）以发送密码重置邮件。
</Callout>

## 配置示例

### 仅 SSO（禁用邮箱密码）

```bash
AUTH_DISABLE_EMAIL_PASSWORD=1
AUTH_SSO_PROVIDERS=google,github
```

### 邮箱密码 + 邮箱验证

```bash
AUTH_EMAIL_VERIFICATION=1
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=noreply@example.com
SMTP_PASS=your-password
```

<Callout type={'tip'}>
  前往[环境变量](/zh/docs/self-hosting/environment-variables/auth)查看所有身份验证相关变量的详细信息。
</Callout>
