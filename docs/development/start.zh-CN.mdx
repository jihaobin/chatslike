# 技术开发上手指南

<Callout type={'warning'}>
  本项目当前只维护中文开发文档。英文文档可能包含过期的目录、路由、命令和产品行为，关键结论请以中文文档和当前代码为准。
</Callout>

本仓库是 LobeHub 的定制项目，而不是未修改的上游镜像。第一次接手时，请先阅读 [项目接手与维护指南](/zh/docs/development/basic/handoff)，其中包含项目定位、定制能力、架构边界、启动方式、验证流程和当前问题。

## 技术栈

- **框架**：Next.js 16 + React 19
- **SPA**：Vite + React Router DOM
- **语言**：TypeScript
- **UI**：`@lobehub/ui`、antd、antd-style
- **状态与请求**：zustand、SWR、tRPC
- **服务端**：Next.js Route Handler、tRPC Router、Server Service
- **数据库**：PostgreSQL + Drizzle ORM
- **基础服务**：Redis、RustFS、SearXNG
- **Agent**：`@lobechat/model-runtime`、`@lobechat/agent-runtime` 和内置工具包
- **测试**：Vitest、Cucumber、Playwright

## 最短启动路径

```bash
pnpm install
bun run dev:docker
pnpm db:migrate
bun run dev
```

默认情况下，Next.js 运行在 `http://localhost:3010`，Vite SPA 运行在 `http://localhost:9876`。只开发 SPA 时可运行 `bun run dev:spa`，并使用终端输出的 Debug Proxy URL。

详细的环境变量、运行模式和故障排查见 [环境设置指南](/zh/docs/development/basic/setup-development)。

## 开发约定

- `src/routes/` 只保留薄路由节点，领域 UI 放在 `src/features/`。
- 桌面路由必须同时更新 `desktopRouter.config.tsx` 与 `desktopRouter.config.desktop.tsx`。
- 样式优先使用 `createStaticStyles` 和 `cssVar.*`。
- 用户可见文本必须走 react-i18next。
- 单元测试使用聚焦的 Vitest 命令，不运行耗时的全量测试。
- 修改代码前检查 Git 工作区，不覆盖他人未提交的改动。

完整规范见根目录 `AGENTS.md`（如当前工作区提供）及 `.agents/skills/` 下的领域指南。
